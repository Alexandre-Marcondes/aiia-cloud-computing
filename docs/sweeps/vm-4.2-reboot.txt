SLS Practice 1 -- Part 4.2: multi-camera sweep after a full VM reboot (diagnostic)
================================================================================
The VM was rebooted via `az vm restart` (clears swap + page cache), then, with a
per-N receiver service restart (hard stop/start), each N was run for 60 s.
Purpose: test whether a full reboot restores the earlier healthy regime.
Result: N=4 healthy (baseline fine); N=13,14 collapse -> the high-N limit is
the CPU throughput edge (~2.6 fps), not memory; a reboot/restart cannot buy CPU.
================================================================================
